# Что запустить на ПК с видеокартой и что вернуть обратно

Ноутбук делает всю разработку и все быстрые прогоны. На ПК с RTX 5060 Ti нужно
ровно то, что не помещается в ноутбук по размеру данных, плюс подтверждение, что
на второй платформе всё сходится.

Проверено 17.09.2026: torch 2.11.0+cu128, вычислительная способность (12, 0),
матричное умножение на устройстве отработало. Риск sm_120 снят.

---

## Прежде чем начинать

```powershell
git pull
uv sync --extra gpu
```

Если `uv` ругается на конфликт с группой `cpu` — в окружении стоят обе. Удалить
`.venv` и повторить `uv sync --extra gpu`.

---

## 1. Проба видеокарты, 10 секунд

```powershell
uv run python scripts/gpu_smoke.py
```

Ожидается `supported: True` и capability `(12, 0)`. Если после `uv sync` проба
перестала проходить — дальше не идти, прислать текст ошибки.

## 2. Тесты на второй платформе, 3–5 минут

```powershell
uv run pytest -m "not integration and not gpu"
```

Ожидается зелёный прогон. Это проверка кроссплатформенности: пути, порождение
процессов, переносы строк. Красный тест здесь — находка, а не помеха, прислать
имя теста и вывод.

## 3. Тот же малый прогон, что на ноутбуке, 5–10 минут

```powershell
uv run rga evaluate --config configs/experiments/gnn.yaml --out experiments/runs/gnn-pc
```

Смысл — сверить платформы. Числа должны совпасть с `docs/thesis/gnn.md` в пределах
разброса между сидами. Большое расхождение означает, что что-то зависит от
платформы, чего быть не должно.

## 4. Полный прогон, около двадцати минут

```powershell
uv run rga evaluate --config configs/experiments/gnn-full.yaml --out experiments/runs/gnn-full
```

Набор данных `default-history.yaml`: 51 314 событий, 30 705 кандидатов обучающего
среза, граф из 7 745 узлов и 17 009 рёбер против 1 969 и 4 139 у малого.

**Оценка времени изменилась в модуле 5.** До векторизации выборки отрицательных
примеров прогон стоил около 2.5 часов, и видеокарта почти не помогала: из 3.0
секунд на эпоху 2.8 уходило на питоновский цикл, который ускоритель не трогает.
После векторизации замер на том же наборе данных даёт 0.01 секунды на выборку
против прежних 2.8 и 0.10 секунды на два компонента вместе против прежних 3.0.
Проверить на месте: `uv run python scripts/profile_epoch.py`.

Теперь на проход по сети приходится почти всё время эпохи, и видеокарта наконец
имеет смысл. Точную цифру по ПК стоит прислать — на ноутбуке она получена без
ускорителя.

---

## Что вернуть обратно

`experiments/runs/` лежит в `.gitignore` намеренно: прогон воспроизводится из
рецепта, в репозиторий попадает только опубликованная таблица. Поэтому вернуть
нужно текстом:

1. Вывод `scripts/gpu_smoke.py` целиком.
2. Итог `pytest`: строку с числом пройденных и упавших.
3. Содержимое `experiments/runs/gnn-pc/results.md` — для сверки платформ.
4. Содержимое `experiments/runs/gnn-full/results.md` — это таблица, которая пойдёт
   в работу как `docs/thesis/gnn-full.md`.
5. Сколько по времени заняли пункты 3 и 4.
6. Вывод `uv run python scripts/profile_epoch.py` — стоимость эпохи на видеокарте
   против ноутбучной.

Файлы небольшие, их можно просто вставить в чат. Публикацию в `docs/thesis/` и
коммит сделаю на ноутбуке — так история остаётся линейной и не приходится
разбираться с двумя машинами, пишущими в одну ветку.
