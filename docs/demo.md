# Порядок демонстрации

Две части. Основная идёт на синтетике и ни от чего не зависит; финал переключает ту же
систему на живой `opens3-rebac`. Если живая часть не поднимется, теряется только она.

## Заранее, не в день защиты

```bash
uv sync --extra cpu --extra service --extra ml --extra neo4j
uv run rga train --config configs/train/gnn-supervised.yaml --out artifacts/gnn-supervised
uv run rga serve --config configs/service/synthetic.yaml
```

Открыть `http://127.0.0.1:8000`, убедиться, что список заполнен, карточка открывается,
рисунок окрестности рисуется. Обучение занимает несколько минут и на защите не
запускается никогда.

## Часть 1: синтетика

1. **Список.** Окно оценки, 637 изменений прав, отсортированы по убыванию оценки.
   Сказать, что это очередь на ручной разбор, а не список нарушителей.
2. **Карточка.** Открыть верхнее изменение. Показать три вещи по очереди:
   - формулировки «что здесь необычного» — наблюдения, не вердикты;
   - рисунок окрестности: пунктиром выделено оцениваемое изменение, толщина связи
     показывает, насколько она держала оценку;
   - таблицу вклада признаков; отдельно показать строку с пометкой «источник не
     сообщает» и объяснить, что маскирование — не ноль.
3. **Фильтры.** Отфильтровать по субъекту, показать, что у одного субъекта несколько
   изменений подряд.
4. **Второй инцидент** другого типа — например, вступление в группу, — чтобы было видно,
   что объяснение меняется вместе с природой изменения.

## Часть 2: живой движок

```bash
cd ../opens3-rebac && git checkout feat/graph-timestamps && docker compose up -d --wait neo4j
cd ../rebac-graph-anomaly
uv run python scripts/fill_live_graph.py --config configs/generator/small-history.yaml
uv run rga serve --config configs/service/opens3.yaml
```

Проверено 17.09.2026: 9747 рёбер записывается примерно за минуту, адаптер читает граф
на уровне возможностей 2, в окне семи дней 68 изменений.

В строке состояния показать: источник `живой opens3-rebac`, уровень возможностей 2.
Подчеркнуть, что код тот же самый, заменена только конфигурация.

## Финал

Выдать себе `admin` штатным gRPC-вызовом к движку, нажать «Обновить», найти изменение
в списке и открыть карточку. В формулировках должно быть «Право выдал сам субъект».

Если изменение оказалось не в верхней части списка — так и сказать. Это измеренное
поведение системы, а не повод перезапускать демонстрацию до красивого результата.

## Если что-то не поднялось

Синтетическая часть уже показала всё, что работа утверждает: ранжирование, объяснение
признаками, объяснение структурой и текстовые формулировки. Работа адаптера с живым
движком закреплена интеграционным тестом `tests/service/test_fill_live_graph.py`,
который читает граф, записанный движком, и проверяет уровень возможностей 2.
